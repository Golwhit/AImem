# MemLab — LLM From Scratch

An experimental language model built from axiomatic constraints upward, not from massive corpora downward.

## Philosophy

**Teaching to learn**, not memorizing to reproduce.

The model starts with law-like constraints (microblocks) that define what *can* exist. From these, valid patterns emerge. Patterns become predictive. Predictions become thoughts. Thoughts become actions. Actions become memories. Memories cluster. Clusters connect. Connections strengthen and decay. Points gravitate into galaxies. Galaxies form dimensions. Dimensions shift universes.

This is **organic growth** — a developmental architecture, not a static transformer.

## Architecture Layers

| Layer | Name | Function |
|---|---|---|
| 0 | **Laws** | Axiomatic constraints — what cannot exist |
| 1 | **Microblocks** | Valid character/configurations built from laws |
| 2 | **Patterns** | Recognized valid sequences |
| 3 | **Predictions** | Probabilistic transitions within constraints |
| 4 | **Thoughts** | Coherent prediction chains |
| 5 | **Actions** | Output generation |
| 6 | **Memories** | Persisted states |
| 7+ | **Clusters → Galaxies → Dimensions → Universes** | Higher-order emergent structures |
